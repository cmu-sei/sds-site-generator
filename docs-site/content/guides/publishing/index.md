# Publish and operate

Validate and deploy a complete site, then keep team builds and browser search
working reliably.

1. [Build and deploy](deployment.md): validate content, understand generated
   output, and publish to a static host or GitHub Pages.
2. [Team workflows and CI](team-workflows.md): collaborate through pull requests,
   automate checks, pin versions, and protect private documentation.
3. [Search and hosting](search-and-hosting.md): improve discoverability, deploy
   consistent updates, diagnose search, and support restricted networks.
4. [Licensing and publication rights](licensing.md): distinguish the generator's
   license, third-party notices, and permission to publish your own content.

For changes to an existing site's routes or imported content, continue to
[Maintain and migrate](../maintenance/index.md).
