# Start here

Install the generator, create a first site, and configure its identity and
publishing URL. No web framework experience is needed.

1. [Create your first site](getting-started.md): choose an installation method,
   scaffold a new directory, and learn the preview/check/build commands.
2. [Configure the site](configuration.md): set every `site.toml` option and
   choose automatic or custom main navigation.

Already have a working site? Continue to [Write content](../authoring/index.md).
Bringing an existing Markdown corpus? Start with
[importing and troubleshooting](../maintenance/importing.md).
