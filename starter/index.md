# Welcome

Your new documentation website is ready. Edit this file to make it your own.

## Start here

Write in plain text. Use headings to organize your ideas, and the website will
build navigation and a table of contents for you.

- **Bold text** draws attention.
- Lists make steps easy to follow.
- [Read the writing guide](guides/index.md) for examples.

## Find anything

Choose **Search** in the header to search every published page. Search runs
entirely in your browser; no account or external service is needed.
